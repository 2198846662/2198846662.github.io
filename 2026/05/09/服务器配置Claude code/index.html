四、VSCode Remote-SSH 使用 Claude Code 插件

不用单独安装 Claude Code CLI，而是在 VSCode Remote-SSH 里安装插件版 Claude Code。

正确做法是：

VSCode 连接服务器
打开 Extensions
搜索 Claude Code
点击 Install in SSH: luyao

注意不是安装在本地 Windows，而是安装到远程 SSH 环境。

配置导出后，重载 VSCode：

Ctrl + Shift + P
Developer: Reload Window

然后打开 Claude Code 插件，它成功显示了 DeepSeek V4 Pro，说明读取到了项目里的：

.claude/settings.local.json

五、聊天记录保存位置

Claude Code 插件的聊天记录一般保存在服务器上：

~/.claude/projects/

具体形式类似：

~/.claude/projects/<项目目录对应的名字>/.jsonl

查找最近的对话：

find ~/.claude/projects -name “*.jsonl” -exec ls -lt {} + | head -20

查看某个会话：

less ~/.claude/projects/某个项目目录/某个session.jsonl

注意：

.claude/settings.local.json

是配置文件，不是聊天记录。
